# METADWIPA 가상 뮤지엄: 반튼 × 상주

인도네시아 반튼(Banten)과 대한민국 상주(Sangju)의 유물·유적을 반튼 5점, 상주 3점으로 소개하는 가상 전시 페이지입니다.
*바다의 향신료 길, 땅과 강의 명주 길*

- 라이브 페이지: https://groot512.github.io/banten-sangju-virtual-museum/
- 언어: 한국어 / English / Bahasa Indonesia
- 베타 범위 조정(교류 핵심 3축): 상주 전시는 삼백(三白)인 명주(누에·비단), 쌀(공검지·벼농사), 곶감으로 구성합니다.

## 전시 구성 (5+3)

- 반튼 5점: 수로소완 궁전 터, 석제 후추 맷돌·무역 도자기, 키 아묵 청동 대포, 아발로키테스바라 사원, 대나무 앙클룽(바두이)
- 상주 3점(삼백 三白): 명주 베틀 도구(명주), 공검지·공갈못(쌀), 곶감(이미지 준비 중)

## 비교 뷰어 (주제 비교 2쌍)

주제에 따른 비교이며, 두 지역 사이의 직접 교역이나 동일 기능을 입증하는 짝은 아닙니다.

- 후추 맷돌·무역 도자기 ↔ 명주 베틀 (무역·직물)
- 대나무 앙클룽 ↔ 공검지 (벼농사·공동체)

## 페이지 구성

히어로 → 전시 총론 → PILLAR 01 역사·PILLAR 02 문화 → 공검지 하이라이트 → PILLAR 03·04(보조) → 동서 지역사 연표 → 비교 뷰어 → 전체 컬렉션 → 3D 공간 계획안(기획 단계)

## 주요 기능

- KO / EN / ID 실시간 전환
- 2쌍 1:1 비교 뷰어
- 반튼·상주·유물·유적·전통 산물 필터와 키워드 검색
- 카드별 상세 해설 모달과 이미지 출처 표기 (출처 미확인 항목은 "출처 확인 필요")
- 동서 지역사 대비 연표
- 모바일 대응 레이아웃
- 3D 공간 배치는 기획안이며, 현재 3D 뷰어는 포함하지 않습니다.

## 구성

정적 페이지입니다. `index.html`이 진입 파일이며 전시 이미지는 `images/`(WebP), 히어로 이미지는 루트의 `metadwipa_hero_banner.webp`에 있습니다. 곶감 카드는 이미지가 없어 "이미지 준비 중" 자리만 표시하며, 이미지 로드에 실패한 경우에도 같은 자리 표시로 대체됩니다. 별도 빌드 과정은 없습니다.
