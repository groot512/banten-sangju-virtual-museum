# METADWIPA 가상 뮤지엄: 반튼 × 상주

인도네시아 반튼(Banten)과 대한민국 상주(Sangju)의 유물·유적을 5점씩 나란히 소개하는 가상 전시 페이지입니다.
*바다의 향신료 길, 땅과 강의 명주 길*

- 라이브 페이지: https://groot512.github.io/banten-sangju-virtual-museum/
- 언어: 한국어 / English / Bahasa Indonesia

## 전시 구성 (5+5)

| 반튼 | 상주 |
|---|---|
| 수로소완 궁전 터 | 상주 경상감영지 |
| 석제 후추 맷돌 및 무역 도자기 | 상주 전통 명주 베틀 도구 |
| 키 아묵 청동 대포 | 정기룡 장군 신검 및 유품 |
| 아발로키테스바라 사원 | 도남서원 |
| 대나무 앙클룽(바두이) | 상주 동학 전적 및 민중 공동체 유산 |

## 주요 기능

- KO / EN / ID 실시간 전환
- 5쌍 1:1 비교 뷰어
- 반튼·상주·유물·유적 필터와 키워드 검색
- 카드별 상세 해설 모달과 이미지 출처 표기 (출처 미확인 항목은 "출처 확인 필요")
- 동서 지역사 대비 연표
- 모바일 대응 레이아웃
- 3D 공간 배치는 기획안이며, 현재 3D 뷰어는 포함하지 않습니다.

## 구성

정적 페이지입니다. `index.html`이 진입 파일이며 이미지는 `images/`(WebP)에 있습니다. 별도 빌드 과정은 없습니다.
